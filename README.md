# Healing Rituals website preview

Open `index.html` in a browser to view the static preview, or run a local web server from this folder:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Before publishing

- Replace the placeholder email and consultation link.
- Replace the artistic Lauren placeholder with a real portrait.
- Add approved testimonials.
- Confirm professional title, licensure, service descriptions, and scope language.
- Add privacy, cancellation, and informed-consent pages.
- Connect analytics only after consent and privacy settings are finalized.

The two raster images in `assets/` were generated as original preview placeholders.
